## ⚙️ Системні Змінні (Scoreboards та Теги)
Для коректної роботи датапаку на сервері необхідні наступні об'єкти (Scoreboard objectives). **Вони автоматично створюються під час `/reload` або старту сервера через скрипт `factions:load`:**

*   `forge_temp` (dummy) — використовується для математичних обчислень кількості предметів під час кастомного крафту на Верстаках.
*   `block_timer` (dummy) — таймер зворотного відліку в тіках (20 тіків = 1 секунда) для тимчасових магічних блоків/бар'єрів.

**Глобальні Entity Tags:**
*   `t1_workbench_new` — тег для сутності `marker`, яка слугує центром Верстака Потолочі.
*   `temp_block` — тег для маркерів, що відповідають за тимчасові блоки (зникають, коли `block_timer` <= 0).
*   Теги крафту (`craft_1`, `craft_2`, `craft_3`, `crafted`) — тимчасові теги, що присвоюються маркеру верстака під час успішної транзакції крафту для запуску візуальних ефектів та очищення інгредієнтів.

## 🔮 Система Заклять (Через Книги)
Закляття кастуються гравцем через механіку підписання книги з пером (`minecraft:writable_book`). 
Використовується тригер досягнень `minecraft:inventory_changed`, який сканує інвентар на наявність `minecraft:written_book` із конкретною назвою (`title`) у компоненті `minecraft:written_book_content`.

**Список існуючих заклять:**
1.  **Craftus Super** (`title: "craftus super"`) -> запускає функцію `factions:spell_craftus` (активує крафт).
2.  **Flamus Hominus** (`title: "flamus hominus"`) -> запускає функцію `factions:spell_flamus`.
3.  **Oculus Mandere** (`title: "oculus mandere"`) -> запускає функцію `factions:spell_oculus`.
4.  **Wunderlafus** (`title: "wunderlafus"`) -> запускає функцію `factions:spell_wunderlafus`.

> **Важливо для ШІ:** У версії 1.21.11 предикат у файлах advancements для `written_book_content.title` повинен бути **звичайним рядком** (`"title": "назва"`), а не raw-об'єктом.

## 🛠️ Кастомний Крафт (Верстак Потолочі)
Реалізований через in-world взаємодію предметів, що лежать на землі, та сутності `marker`.

1.  **Отримання верстака:** Звичайний крафт (файл `t1_workbench.json`), де гравець отримує яйце призову кажана зі зміненим `entity_data`, що спавнить `marker` із тегом `t1_workbench_new`.
2.  **Механіка сканування:** Функції виконуються від імені маркера (`execute as @e[type=marker,tag=t1_workbench_new] at @s...`), який сканує викинуті предмети в радіусі 2 блоків (`distance=..2`).
3.  **Запобігання багам (КРИТИЧНО):** У версії 1.21+ гра внутрішньо ініціалізує компонент `custom_data` для всіх предметів. Тому для фільтрації ванільних інгредієнтів від кастомних артефактів використовується селектор **`[!minecraft:custom_name]`** замість `[!minecraft:custom_data]`.

**Базові Рецепти (Артефакти):**
*   **Кінетичний сплав:** Звичайне золото(2), залізо(1), незеритовий брухт(2), редстоун(1), світлопил(1). Віддає предмет з `custom_data={kinetic_alloy:1b}`.
*   **Кристал глибин:** Алмаз(1), смарагд(1), лазурит(1), аметист(1), кварц(1). Віддає предмет з `minecraft:custom_data={deep_crystal:1b}`.
*   **Фрагменти зірки:** Розщеплює Зірку Незеру на Жовтий Уламок(3), Срібний Уламок(2) та Кришталь Зірки(1).

**Складні Рецепти (Екіпірування та Інструменти):**
*   **Жаб'ячі світильники (по 16 шт. кожного):** Мох(32), світлоягоди(16).
*   **Ритуальний ніж (Темно-червоний):** Кінетичний сплав(1), кістка(1), шкура(1). Має Looting 10 та міцність 10.
*   **Набір рейок (64 звичайних, 16 електро, 16 активуючих):** Залізо(16), редстоун(24), кварц(4).
*   **Камінь левітації (Синій):** Кристал глибин(1), глибокосланець(8), кругляк(8), незерак(8). Базовий предмет: синій барвник. При триманні в лівій руці накладає левітацію 2.
*   **Підсвічувач (Світло-жовтий):** Пил світлокаменю(16), папір(1), порох(6). Consumable. Видає ефект світіння всім на 1 хвилину в радіусі 100 блоків.
*   **Іржаві Стріли (32 шт):** Стріли(16), залізо(4), відро води(1). Накладають миттєву шкоду 1 та висушування 1.
*   **Лікувальний Шприц:** Залізо(2), пляшка(1), око павука(1), гнила плоть(1), кісткове борошно(1). Базовий предмет: дерев'яний меч. Зцілює ціль атаки, наносить шкоду власнику 2 рівня, міцність 10.
*   **Блок родючого аметисту:** Аметист(16), кристал глибин(1), блок аметисту(1).
*   **Ліхтар будівельника (Оранжево-жовтий):** Ліхтар(1), золотий фрагмент зірки(1), золотий злиток(2). Збільшує дистанцію взаємодії блоків до 10 при триманні в лівій руці.
*   **Джаггернаут Сет (Срібний):** Кінетичний сплав(32), шкура(8), кристал глибин(1), зелений барвник(4), сяйний чорнильний мішок(1). Комплект броні (база: незерит) зі збільшеними показниками опору відкиданню(0.2), вибухам(0.2), броні(+3/8/6/3), здоров'я(+2 на елемент), міцності броні(+3) та швидкості руйнування(+0.1).

## ⚔️ Механіки Фракцій та Атрибути
Замість постійних ефектів зілля (potion effects), використовуються сучасні базові атрибути (`/attribute` або `attribute_modifiers` в компонентах предметів) для реалізації пасивних здібностей:
*   `minecraft:generic.step_height` (базове 0.6) -> збільшується для Потолочі до `1.0+`, дозволяючи заходити на цілі блоки/паркани.
*   `minecraft:generic.gravity` (базове 0.08) -> зменшується для Піднесених для ефекту "повільного падіння".
*   `minecraft:generic.jump_strength` -> налаштовується для Піднесених.
*   `minecraft:player.sneaking_speed` -> швидке пересування навпочіпки для певних класів.

## 🖥️ Архітектура Сервера
*   **Оптимальне Ядро:** Paper / Purpur (з модом Lithium для Fabric).
*   **Вимоги до "Заліза":** Оскільки сканування інвентарів/маркерів відбувається 20 разів на секунду (`tick.mcfunction`), сервер вимагає процесора з високою продуктивністю на ядро (наприклад, **Ryzen 9 7950X3D**) та швидку оперативну пам'ять (**DDR5**). 
*   **Накопичувач:** Виключно NVMe SSD для уникнення фризів під час генерації кастомного світу (`overworld.json`).
